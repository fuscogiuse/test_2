# Piano Dettagliato: AI Marketing Assistant

## Obiettivo
Creare un AI assistant che conosca a fondo il cliente e sia in grado di produrre qualsiasi materiale di marketing coerente, efficace e strategicamente allineato.

---

## FASE 1 — Ricerca e Raccolta Informazioni sul Cliente

### 1.1 Identità del Brand

| Info da raccogliere | Dettaglio |
|---|---|
| Nome azienda / brand | Nome legale e nome commerciale |
| Mission | Perché esiste l'azienda? Qual è il suo scopo? |
| Vision | Dove vuole arrivare nei prossimi 3-5-10 anni? |
| Valori fondamentali | I 3-5 valori non negoziabili del brand |
| Storia del brand | Anno di fondazione, tappe chiave, evoluzione |
| Fondatore/i | Chi sono, background, motivazione personale |
| Unique Selling Proposition (USP) | Cosa rende il brand diverso da tutti gli altri? |
| Brand Promise | Qual è la promessa fatta al cliente? |
| Posizionamento di mercato | Premium, mid-range, budget? Innovatore, tradizionale? |

### 1.2 Prodotti / Servizi

| Info da raccogliere | Dettaglio |
|---|---|
| Catalogo completo | Lista di tutti i prodotti/servizi offerti |
| Descrizione dettagliata | Feature, benefici, specifiche tecniche per ciascuno |
| Pricing e modello di business | Prezzi, piani, abbonamenti, one-time, freemium |
| Prodotto/servizio di punta | Qual è il bestseller o flagship? |
| Roadmap prodotto | Cosa è in arrivo? Lanci futuri? |
| Processo di acquisto | Come si compra? Online, in negozio, tramite consulente? |
| Garanzie e politiche | Reso, garanzia, supporto post-vendita |

### 1.3 Target Audience / Buyer Personas

Per **ogni** segmento di clientela, raccogliere:

| Info da raccogliere | Dettaglio |
|---|---|
| **Dati demografici** | Età, genere, localizzazione, reddito, istruzione, professione |
| **Dati psicografici** | Interessi, hobby, stile di vita, valori personali |
| **Pain points** | Quali problemi/frustrazioni hanno? Cosa li tiene svegli la notte? |
| **Desideri e aspirazioni** | Cosa vogliono ottenere? Come vogliono sentirsi? |
| **Obiezioni all'acquisto** | Perché NON comprerebbero? Dubbi, paure, resistenze |
| **Trigger di acquisto** | Cosa li spinge a comprare ORA? Evento scatenante? |
| **Customer journey** | Come scoprono il brand? Che percorso fanno fino all'acquisto? |
| **Canali preferiti** | Dove passano il tempo online/offline? Social, blog, podcast? |
| **Linguaggio** | Come parlano? Gergo, tono, espressioni tipiche? |
| **Influencer/fonti fidate** | Chi ascoltano? Di chi si fidano? |

### 1.4 Analisi Competitiva

| Info da raccogliere | Dettaglio |
|---|---|
| Top 3-5 competitor diretti | Chi sono, cosa offrono, pricing |
| Competitor indiretti | Alternative non ovvie che il cliente potrebbe scegliere |
| Punti di forza dei competitor | In cosa sono bravi? |
| Punti di debolezza dei competitor | Dove falliscono? Recensioni negative? |
| Posizionamento competitor | Come si posizionano? Che messaggio usano? |
| Gap di mercato | Cosa NON offre nessuno? Opportunità inesplorate? |
| Share of voice | Chi domina la conversazione nel settore? |

### 1.5 Mercato e Settore

| Info da raccogliere | Dettaglio |
|---|---|
| Dimensione del mercato | TAM, SAM, SOM |
| Trend di settore | Cosa sta cambiando? Innovazioni? Disruption? |
| Stagionalità | Ci sono periodi di picco o di calo? |
| Regolamentazioni | Normative specifiche del settore? |
| Barriere all'ingresso | Cosa rende difficile entrare nel mercato? |

## FASE 5 — Framework Operativo dell'AI

### 5.1 Cosa l'AI Deve Saper Produrre

Con tutte le informazioni raccolte, l'AI sarà in grado di generare:

#### Contenuti Social
- [ ] Post per Instagram (caption + suggerimento visual)
- [ ] Post per LinkedIn (thought leadership, case study)
- [ ] Post per Facebook
- [ ] Thread per X/Twitter
- [ ] Script per Reel / TikTok
- [ ] Stories con CTA

#### Email Marketing
- [ ] Welcome sequence (5-7 email)
- [ ] Nurture sequence
- [ ] Sales sequence
- [ ] Email promozionali one-shot
- [ ] Newsletter periodiche
- [ ] Win-back sequence
- [ ] Abandoned cart sequence

#### Copywriting
- [ ] Landing page (hero, benefici, social proof, CTA)
- [ ] Sales page (long-form)
- [ ] Pagine prodotto
- [ ] About page
- [ ] Homepage
- [ ] Lead magnet (ebook, checklist, template)

#### Advertising
- [ ] Facebook/Instagram Ads (copy + headline + CTA)
- [ ] Google Ads (search, display)
- [ ] LinkedIn Ads
- [ ] YouTube Ads (script)
- [ ] Retargeting ads

#### Content Marketing
- [ ] Articoli blog SEO-ottimizzati
- [ ] Pillar content
- [ ] Case study

- [ ] Infografiche (testo + struttura)
- [ ] Script video / podcast

#### Brand & PR
- [ ] Comunicati stampa
- [ ] Bio aziendali (varie lunghezze)
- [ ] Pitch per media/podcast
- [ ] Presentazioni commerciali
- [ ] Script per eventi/webinar

#### Sales Enablement
- [ ] Script di vendita
- [ ] FAQ
- [ ] Gestione obiezioni
- [ ] Proposta commerciale template
- [ ] Follow-up sequence

### 5.2 Regole Operative per l'AI

L'AI deve sempre:

1. **Mantenere coerenza** — Ogni output deve essere allineato al brand voice definito
2. **Partire dal perché** — Ogni contenuto parte dal problema del cliente, non dal prodotto
3. **Usare framework collaudati** — PAS, AIDA, StoryBrand, 4P a seconda del contesto
4. **Includere CTA** — Ogni contenuto deve avere un'azione chiara per il lettore
5. **Adattare il tono al canale** — LinkedIn ≠ Instagram ≠ Email
6. **Citare dati quando possibile** — Numeri, risultati, prove sociali
7. **Pensare mobile-first** — Testi scannable, paragrafi brevi, hook iniziale forte
8. **Rispettare il customer journey** — TOFU, MOFU, BOFU: contenuti diversi per fasi diverse

### 5.3 Prompt Structure Consigliata

Quando si chiede qualcosa all'AI, usare questa struttura:

```
RUOLO: Sei un esperto marketing strategist per [BRAND]
CONTESTO: [Fase del funnel / Obiettivo specifico / Campagna]
TARGET: [Buyer persona specifica]
CANALE: [Dove verrà pubblicato]
FORMATO: [Tipo di contenuto richiesto]
TONO: [Riferimento alla brand voice]
VINCOLI: [Lunghezza, parole chiave, CTA specifiche]
ESEMPI: [Contenuti passati che hanno funzionato come riferimento]
```

## FASE 6 — Checklist di Implementazione

### Step 1: Raccolta Dati (Settimana 1-2)
- [ ] Intervista approfondita al cliente (usare le domande delle Fasi 1-4)
- [ ] Raccolta materiali esistenti (sito, social, email, ads)
- [ ] Analisi competitor (almeno top 3)
- [ ] Analisi recensioni e feedback clienti
- [ ] Raccolta dati analytics (Google Analytics, social insights, email stats)

### Step 2: Organizzazione Knowledge Base (Settimana 2-3)
- [ ] Creare documento "Brand Bible" con tutte le info raccolte
- [ ] Definire buyer personas dettagliate (schede individuali)
- [ ] Creare swipe file di copy/contenuti approvati
- [ ] Documentare la brand voice con esempi positivi e negativi
- [ ] Mappare il customer journey per ogni persona

### Step 3: Setup AI System (Settimana 3-4)
- [ ] Caricare la knowledge base nel sistema AI scelto
- [ ] Creare prompt template per ogni tipo di contenuto
- [ ] Testare output su tutti i formati
- [ ] Validare con il cliente i primi output
- [ ] Iterare e raffinare i prompt in base al feedback

### Step 4: Operatività (Ongoing)
- [ ] Calendario editoriale mensile generato dall'AI
- [ ] Review settimanale dei contenuti prodotti
- [ ] Aggiornamento mensile della knowledge base con nuovi dati/risultati
- [ ] A/B testing sui contenuti generati
- [ ] Report mensile performance vs obiettivi
